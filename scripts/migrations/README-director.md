# Director's Brief — Setup

The Director's Brief lives at `/director` on the Pulse app (`pulse.fabrick.agency/director`). Replaces the static-HTML brief generated by `_scripts/build-director-brief.py` in the Client-System repo.

## One-time setup checklist

### 1. Google OAuth client (only Tom can do this)

1. Go to https://console.cloud.google.com/apis/credentials
2. Use (or create) a project for Fabrick.
3. Create **OAuth 2.0 Client ID** → Web application.
4. Authorised redirect URIs:
   - `https://pulse.fabrick.agency/api/auth/callback/google`
   - `http://localhost:3000/api/auth/callback/google` (for local dev)
5. Copy the **Client ID** and **Client secret**.

### 2. Env vars on Vercel (Production + Preview + Development)

Add these to the Pulse project on Vercel:

```
GOOGLE_CLIENT_ID=<from step 1>
GOOGLE_CLIENT_SECRET=<from step 1>
AUTH_SECRET=<generate with: openssl rand -base64 32>
AUTH_URL=https://pulse.fabrick.agency
DIRECTOR_ALLOWED_EMAILS=tom.colgan@fabrick.agency
```

Then locally: `vercel env pull .env.local` to mirror them.

### 3. Run the SQL migration

```bash
# In the Neon SQL editor or via psql:
psql "$DATABASE_URL" -f scripts/migrations/003_director_brief.sql
```

This creates `director_tasks`, `director_task_blocks`, `director_task_notes`, `director_ingestion_state`.

### 4. Seed tasks from the master task list

```bash
cd /Users/tom/Work/Fabrick/sustainability-hub
npm run migrate:director -- --dry-run   # preview parsing
npm run migrate:director                # actually insert
```

Idempotent on the `ref` column — safe to re-run after the master list changes.

### 5. Test locally

```bash
npm run dev
# Open http://localhost:3000/director
# Sign in with tom.colgan@fabrick.agency
```

### 6. Deploy

Push to the `main` branch — Vercel auto-deploys.

## What lands when

- **Phase 0 (now):** auth + DB + seed task list. Page renders open tasks from DB.
- **Phase 1:** live MS365 calendar feed + Georgia activity feed (queries Digital Tool DB directly).
- **Phase 2:** tickable tasks, inline edit, manual add.
- **Phase 3:** email + Fireflies ingestion workers (Vercel cron).
- **Phase 4:** FlowSavvy-style drag-and-drop time blocks.
- **Phase 5:** daily 07:00 summary email, mobile responsive, deprecate the local Python cron.
